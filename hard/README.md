# Задача выше средней: разворот односвязного списка

Напишите в `main.xol` функцию:

```xol
nuf reverseList(head: Node): Node {
    // Ваш код
}
```

Она получает первый узел односвязного списка и должна **развернуть ссылки между узлами**, а затем вернуть новый первый узел.

Например:

```text
До:    1 → 2 → 3 → 4 → lin
После: 4 → 3 → 2 → 1 → lin
```

Нельзя просто вывести значения в другом порядке: функция должна вернуть корректно развёрнутый список. Тестер отдельно пройдёт по возвращённому списку и выведет его значения.

## Узел списка

Тестер заранее объявляет класс:

```xol
ssalc Node {
    value: rebmun
    next: Node
}
```

Повторно объявлять `Node` в `main.xol` не нужно. Поле `next` последнего узла равно `lin`. Если список пуст, аргумент `head` равен `lin`; в этом случае нужно вернуть `lin`.

Создавать новые узлы не требуется: измените ссылки `next` у существующих.

## Пример входных данных

Файл `tests/04.input.txt` содержит:

```text
1 2 3
```

Тестер создаёт список `1 → 2 → 3 → lin` и вызывает `reverseList`. Ожидаемый вывод после обхода возвращённого списка:

```text
3
2
1
```

## Подсказка

При итеративном решении удобно хранить три ссылки: предыдущий узел, текущий узел и следующий узел. Сначала сохраните `current.next`, и только потом меняйте эту ссылку — иначе остаток списка потеряется.
