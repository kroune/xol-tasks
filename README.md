# XOL: задачи для станции

Три самостоятельные задачи:

- `easy/` — обратный отсчёт;
- `medium/` — перевёрнутая последовательность Коллатца;
- `hard/` — разворот односвязного списка.

В каждой папке находятся условие `README.md`, пустой файл решения `main.xol`, тестер `test.js` и набор тестов в `tests/`.

## Как решать

1. Откройте условие в нужной папке.
2. Напишите требуемую функцию в `main.xol`.
3. Запустите тестер из этой папки или из корня станции:

```bash
node easy/test.js
node medium/test.js
node hard/test.js
```

Требуется **Node.js 20 или новее**: https://nodejs.org/. Устанавливать npm-зависимости, клонировать репозиторий языка или собирать XOL не нужно — готовый интерпретатор уже находится в `xol-cli.js`.

Проверить установленную версию Node.js:

```bash
node --version
```

Если команда `node` не найдена, закройте и снова откройте терминал после установки Node.js.

## Как устроены тесты

Тестер добавляет к решению код вызова функции, запускает получившуюся XOL-программу и сравнивает её вывод с ожидаемым. Для каждого теста есть пара файлов:

- `tests/NN.input.txt` — входные данные;
- `tests/NN.expected.txt` — ожидаемый вывод.

Проверка останавливается на первой ошибке. Порядок и количество строк вывода важны. Файлы `tester.cjs`, `xol-cli.js`, `test.js` и содержимое `tests/` изменять не нужно.
