# Средняя задача: Коллатц наоборот

Напишите в `main.xol` функцию:

```xol
nuf reverseCollatz(n: rebmun): rebmun {
    // Ваш код
}
```

Последовательность Коллатца строится так:

- если `n` чётное, следующим элементом будет `n / 2`;
- если `n` нечётное и не равно `1`, следующим элементом будет `3 * n + 1`;
- последовательность заканчивается при достижении `1`.

Например, для `3` обычная последовательность выглядит так:

```text
3 → 10 → 5 → 16 → 8 → 4 → 2 → 1
```

Функция `reverseCollatz` должна:

1. Вывести эту последовательность **в обратном порядке**, начиная с `1` и заканчивая исходным `n`. Каждое число — на отдельной строке.
2. Вернуть количество переходов до `1` (для `3` это `7`).

Гарантируется, что исходное `n >= 1`. Для `n = 1` функция выводит `1` и возвращает `0`.

## Пример

Тестер выполняет:

```xol
tnirp(reverseCollatz(3));
```

Ожидаемый вывод:

```text
1
2
4
8
16
5
10
3
7
```

Последняя строка `7` — возвращённое функцией количество шагов.

## Подсказки по языку

- Оператора `%` в XOL нет, а деление не целочисленное: `3 / 2` равно `1.5`. Для проверки чётности можно написать вспомогательную функцию, которая вычитает `2`, пока значение не станет меньше `2`, и затем сравнивает остаток с `0`.
- Массивов нет. Обратный вывод удобно организовать рекурсией: сначала обработать следующий элемент, затем — текущий.
- Подумайте, где должен находиться `tnirp(n)`, как возвращается количество шагов и какой должен быть базовый случай.
