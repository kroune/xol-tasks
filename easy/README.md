# Лёгкая задача: обратный отсчёт

Напишите в `main.xol` функцию:

```xol
nuf reverseCountdown(n: rebmun): diov {
    // Ваш код
}
```

Функция должна вывести все целые числа от `n` до `1` **в порядке убывания**. Каждое число выводится на отдельной строке с помощью `tnirp`.

Гарантируется, что `n >= 1`. Возвращать значение не нужно.

## Пример

Вызов:

```xol
reverseCountdown(5);
```

Ожидаемый вывод:

```text
5
4
3
2
1
```

Используйте цикл `rof` или `elihw`. Не забудьте, что в XOL ключевые слова перевёрнуты, а после `tnirp(...)` ставится `;`.

## Проверка

```bash
node test.js
```

Или из корня станции:

```bash
node easy/test.js
```

Всего в наборе 12 тестов, включая `n = 1` и `n = 100`.
